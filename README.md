# 小红书 · 整套同款挂载（Shop the Look）原型

把一条穿搭视频笔记从「只能挂 1 个商品位」变成「挂 14 个」。锚点随画面里的 look
自动切换，点开后视频等比缩小（不裁切），抽屉展示这一身的全部单品，可单买、可一键加购整套。

## 跑起来

```bash
python3 serve.py          # 然后打开 http://localhost:8779
```

必须用这个脚本，不能用 `python3 -m http.server`——后者不支持 HTTP Range，
`<video>` 没法 seek，时间轴跳转会失效。

直接双击 `index.html` 用浏览器打开也可以（`file://` 本身支持 seek）。

视频静音自动播放。如果浏览器拦了自动播放，画面中间会出现播放按钮，点一下即可；
点视频任意位置也能暂停/继续，讲解的时候用得上。

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 全部代码。纯 HTML + CSS + 原生 JS，零依赖、无构建步骤 |
| `assets/look.mp4` | 原视频（@小桃菜奈《秋冬开箱 4套长期主义穿搭look》录屏，110s） |
| `assets/p/*.jpg` | 14 张商品图。从视频对应帧裁切后，用 macOS Vision 的主体分割抠掉背景、合成到浅色底，做成商品图的样子 |
| `serve.py` | 支持 Range 的静态服务器 |
| `build-standalone.py` | 把上面那些打包成单文件版，产出 `dist/` |
| `dist/index.html` | **单文件版**（1.9 MB）。14 张商品图内联成 data URI，只依赖同目录的 `look.mp4` |
| `dist/look.mp4` | 压缩版视频（10 MB）。原分辨率 592×1280，码率 750 kbps，画质和原版几乎无差 |
| `REDCOWORK-PROMPT.md` | 让 REDCowork 从零做的结构化 prompt |
| `NEXT-STEPS.md` | REDCowork 续做指南：怎么上传、怎么验收、它坏了怎么说 |

改完 `index.html` 之后重新打包：

```bash
python3 build-standalone.py
```

`dist/` 存在的意义：REDCowork 这类平台只能传少量文件、目录结构还不由你定，
分散在 `assets/p/` 里的 14 张图路径一定对不上。单文件版把这个问题消掉了。

## 交互

1. **视频页** — 右侧一枚白色胶囊，里面竖排 3–4 个圆形商品锚点（Aritzia 那种形态），
   随 look 自动换一组。换组时浮出「这身同款 N」标签，2.6 秒后淡出，保持画面干净
2. **点锚点** — 视频等比缩小到 54% 并上移（不裁切，四周用模糊背景补），抽屉升起
3. **抽屉** — 选中单品大卡 + 这一身其余单品横向滑动（带 `+` 快捷加购）+ 底部「一键加购整套」
4. **点单品** — 进商详页（按小红书现行商详页还原）
5. **商详页** — 含「搭配这身的其他 N 件」模块，和右上「回看讲解」回跳视频对应秒数
6. **加入购物车 / 立即购买** — 弹出规格选择弹窗（颜色分类 + 尺码 + 数量 + 到手价），按小红书实际弹窗还原
7. **购物车** — 商详页底部购物车图标进入；商品归在「本期笔记同款」店铺组下，
   可勾选、改数量、点图回商详页，合计和结算件数实时联动

两条快捷路径的区别是有意的：抽屉里的 `+` 用商品默认规格直接加购（整套加购的核心体验），
商详页的「加入购物车」才走完整规格选择。

左侧面板的「现状 / 改造后」开关用于作业里做 A/B 对照演示。

## 说明

视频和商品图都取自真实笔记，商品图从视频对应帧裁切，保证「画面里那件 = 挂的那件」。
商品价格、品牌为演示数据；主推款沿用笔记原本挂的致知 ZHIZHI。

## 部署

静态站，拖到 Vercel / Netlify / GitHub Pages 即可。注意宿主要支持 Range 请求
（上述三家都支持），否则视频无法 seek。
